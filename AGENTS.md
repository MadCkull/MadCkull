# Portfolio Typography

Keep the typography system minimal and consistent. Use a maximum of three font families.

The overall typography should feel **spacious, rounded, sleek, modern, premium, and slightly experimental**.

### Recommended Font System

- **Neue Montreal**: Primary font. Use for most of the website including navigation, body text, UI, labels, descriptions, project information, and general content. This should establish the clean, spacious, premium foundation.

- **Bricolage Grotesque**: Display / expressive font. Use for major headings, hero typography, section titles, and selected large statements where we want more personality and experimentation.

- **Space Grotesk**: Technical accent font. Use sparingly for technical metadata, technology names, numbers, tags, code-related information, and other elements that should feel more technical.

### Typography Principle

Neue Montreal should dominate the interface.

Bricolage Grotesque should provide personality.

Space Grotesk should provide technical contrast.

Do not use all three unnecessarily. Typography should remain visually cohesive throughout the website.
